# Vishal Raj — Cybersecurity Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Customize before publishing
1. Replace `#` GitHub and LinkedIn links in `index.html`.
2. Replace `your-email@example.com` with your email.
3. Add your resume as `assets/resume.pdf`.
4. Replace the `VR` avatar later with your own photo if desired.
5. Add the real GitHub repository links for each project.

## Run locally
Open `index.html` in a browser.

## Publish
This project can be hosted free using GitHub Pages.
